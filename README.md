# How to work with branches

## Branches

We have three branches:

- `hr-main` tracks HappyRobot changes.
- `hr-server` tracks the version that `livekit-server` is pointing to.
- `hr-sip` tracks the version that `livekit-sip` is pointing to.

## Tags

- `lk-v1.42.2` LiveKit's upstream tag
- `hr-v1.42.2` HappyRobot version of this LiveKit tag with the `hr-main` changes
